# FinFlow — Personal Finance Hub

A personal-use React + Vite + Tailwind CSS finance tracker for budgets, recurring subscriptions, transactions, net worth, and savings goals.

## Run Locally
```bash
npm install
npm run dev
```

## Push to GitHub (`https://github.com/hnptl5`)
```bash
git init
git add .
git commit -m "Initial commit: FinFlow personal finance app"
git branch -M main
git remote add origin https://github.com/hnptl5/finflow.git
git push -u origin main
```
